Semantic architecture

WBDS는 raw value보다 semantic role을 먼저 정의하고, 그 역할을 theme별 실제 값으로 resolve합니다.

1. Neutral

Canvas, Surface, Text, Border가 읽기와 containment의 기본층을 구성합니다.

2. Action

절제된 olive 계열이 다음으로 중요한 결정이나 행동을 담당합니다.

3. Signal

Warm Sakura는 review, noteworthy, evidence, editorial emphasis처럼 드물게 강조가 필요한 순간에만 사용합니다.

4. Critical

Destructive, revoke, prohibited, severe-error 의미는 Signal과 분리합니다.

5. Other semantic states

Positive, Caution, Info, Focus와 관련 soft surface는 각각 독립된 semantic role로 유지합니다.

Semantic states

theme에 따라 시각 값이 달라져도 Action, Signal, Critical 및 다른 state의 의미는 서로 분리된 채 유지됩니다.

Action

다음으로 중요한 결정이나 행동에 사용합니다. 가장 강한 대비를 화면 전체에 균등하게 뿌리지 않습니다.

Signal

Review, noteworthy, evidence, editorial emphasis에 사용합니다. Signal은 Positive도 아니고 destructive 의미도 아닙니다.

Critical

Destructive, revoke, prohibited, severe-error 의미에만 사용합니다.

Positive

Signal과 별개로 Positive semantic family를 유지합니다.

Caution

Critical과 별개로 Caution semantic family를 유지합니다.

Info

정보 상태가 필요한 컴포넌트는 독립된 Info semantic family를 사용합니다.

Focus

Focus는 Action이나 Signal을 빌려 쓰지 않고 독립된 semantic color를 사용합니다.

Usage

개별 hue 취향이 아니라 semantic role을 기준으로 색상을 선택하고 적용합니다.

값보다 역할을 먼저 선택

WBDS는 Neutral, Action, Signal, Critical 등 semantic purpose를 먼저 정한 뒤 theme별 실제 값으로 resolve합니다. 소비 제품은 이 페이지의 hex 값을 복사하지 말고 public semantic token에 의존해야 합니다.

Signal은 의도적으로 드물게 사용

Warm Sakura는 review, noteworthy, evidence, editorial moment를 표시합니다. 일반 accent처럼 남용하거나 success 의미로 재사용하지 않습니다.

Dark는 inversion이 아니라 semantic remap

D1 Moonlit Desert Midnight는 동일한 semantic role을 moonlit-blue 계열의 night palette로 다시 매핑합니다. Action은 Action, Signal은 Signal, Critical은 Critical로 의미가 유지됩니다.

How to use

대비는 의도적으로 사용하고, Signal은 드물게 유지하며, 상태 의미가 색상 하나에 의존하지 않게 합니다.

DO
  • raw palette value 대신 --wb-color-action 같은 semantic token을 사용합니다.
  • 가장 강한 대비는 다음으로 중요한 결정이나 행동을 위해 남겨둡니다.
  • Signal은 review/noteworthy/evidence/editorial emphasis에 사용합니다.
  • Destructive 또는 prohibited consequence에는 Critical을 별도로 사용합니다.
  • 상태 색상은 언어, semantic structure, 필요한 경우 shape/iconography, behavior와 함께 전달합니다.
DON'T
  • Warm Sakura를 모든 곳의 generic decorative accent로 사용하지 않습니다.
  • Signal을 Positive/success로 사용하지 않습니다.
  • 상태를 색상 하나로만 전달하지 않습니다.
  • Light 값을 기계적으로 반전해 Dark를 만들지 않습니다.
  • semantic token이 있는데 문서의 hex 값을 복사해 사용하지 않습니다.

Accessibility

색상은 의미를 보조하며, semantic structure와 검증된 contrast가 함께 contract를 이룹니다.

WBDS에서 색상은 상태를 보조하는 evidence이며 유일한 evidence가 아닙니다. Light와 Dark mapping은 동일한 상태 의미와 focus visibility를 보존해야 합니다.

7:1Canvas/Surface 위 body text
4.5:1token gate가 검증하는 Muted text, Action, Signal, Critical 및 semantic state text 조합
7:1Soft Signal/Critical/Positive/Caution/Info surface 위 text 및 instrument text
3:1Canvas 대비 Focus color

scripts/validate-tokens.mjs는 이 contrast floor를 Light와 Dark token map 모두에서 검증합니다. token gate 통과가 컴포넌트 수준의 수동 visual/accessibility review를 대체하지는 않습니다.

Maturity & Source

Color는 approved Foundation Alpha이며 Stable이 아닙니다. 실제 consumer adoption에서 contract를 계속 검증해야 합니다.

STATUSApproved Foundation Alpha

A2 / S1 / D1은 선택된 alpha foundation입니다. 실제 consumer adoption에서 문서화된 behavior contract가 검증되기 전에는 Stable로 보지 않습니다.
